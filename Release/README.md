# Bản build Fields of Suspicion

Build ngày 06/11/2026 từ commit 14f1b50 (Unity 6.3 LTS).

| File | Hệ điều hành | Cách chạy |
|---|---|---|
| FieldsOfSuspicion_Windows.zip | Windows 64-bit | Giải nén, chạy `FieldsOfSuspicion.exe` |
| FieldsOfSuspicion_macOS.zip | macOS | Giải nén, mở `FieldsOfSuspicion.app`. Nếu macOS chặn lần đầu: chuột phải vào app, chọn Open |

Trong game: bấm Esc để mở menu (âm lượng, toàn màn hình, độ phân giải, về màn tiêu đề, thoát). Game tự lưu ở cuối mỗi ngày.
